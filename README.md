Zoom Booking Calendar
Небольшой общий календарь бронирования Zoom-слотов для HR-команды.
Сайт размещён на GitHub Pages, а все брони хранятся в общей Google-таблице через Google Apps Script. Поэтому календарь работает одинаково для пользователей с разных компьютеров и браузеров.
Как это устроено
- GitHub Pages — интерфейс календаря (index.html)
- Google Sheets — общая база данных
- Google Apps Script — API между сайтом и таблицей
- LockService — защита от одновременного бронирования одного и того же слота
Возможности
- бронирование Zoom-слотов с шагом 30 минут;
- рабочий диапазон по умолчанию: 07:00–19:00 МСК;
- общий список пользователей;
- закреплённые интервалы;
- удаление брони с подтверждением;
- автоматическая синхронизация общей базы;
- защита от двойного бронирования одного слота;
- админ-режим для редактирования пользователей и закреплённых интервалов.
Структура Google-таблицы
Bookings
Хранит брони.
ID | Дата | День недели | Время | Пользователь | Создано
People
Список пользователей.
ФИО | Цвет | Активен | Порядок
Fixed
Регулярно занятые интервалы.
День | Начало | Окончание | Название | Цвет | Активен
Settings
Настройки календаря.
Основные параметры:
- ссылка Zoom;
- начало рабочего диапазона;
- конец рабочего диапазона;
- шаг сетки;
- часовой пояс.
Публикация
GitHub Pages должен смотреть на:
main / (root)
В корне репозитория должен лежать файл:
index.html
После изменения файла достаточно сделать commit в main. GitHub Pages обновится автоматически.
Apps Script
Apps Script разворачивается как Web App.
Параметры развертывания:
- выполнять от имени владельца;
- доступ — публичный вариант, позволяющий GitHub Pages обращаться к API без авторизации пользователя.
После нового развертывания URL вида:
https://script.google.com/macros/s/.../exec
нужно указать в index.html как APPS_SCRIPT_URL.
Важно
Google Sheet — единственный источник истины. Интерфейс не должен сохранять весь календарь локально и затем целиком перезаписывать таблицу.
Каждое действие отправляется отдельно:
- создать бронь;
- удалить бронь;
- добавить/отключить пользователя;
- добавить/отключить закреплённый интервал.
Это позволяет нескольким пользователям безопасно работать одновременно.
Если что-то сломалось
1. Проверить, открывается ли URL Apps Script /exec.
2. В ответ должен приходить JSON с "ok": true.
3. Проверить, что в репозитории есть index.html именно в корне main.
4. Проверить GitHub Pages → Settings → Pages.
5. Сделать жёсткое обновление страницы (Ctrl+F5).
Админ-доступ
Пароль администратора хранится в index.html в константе ADMIN_PASSWORD.
Для безопасности при передаче проекта лучше заменить его на новый.
